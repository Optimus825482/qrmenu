# P4 — MyBar ve Bildirimler Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Oda QR'ından açılan, canlı şablonla (`docs/referans-misafir_dolum_talebi.html`) kavramsal olarak birebir 5 dilli (AR RTL) MyBar misafir sayfası; oda başına iş günü başına 1 talep (ayarlanabilir), +/- adet, idempotency ve kapatılabilir not çevirisi; kat sorumlusunda zorunlu sesli onay penceresi, karşılama / kapatma / iptal akışları, depo-yönetim izleme penceresi ve Web Push (VAPID) kanalı.

**Architecture:** Yeni modül `src/modules/mybar` (servisler `server/`, arayüz `ui/guest|staff|admin`). Misafir tarafı P5'in `/q/[token]` rotasını ve i18n altyapısını paylaşır: P5'in `resolveGuestToken` birleşim tipi **değişmez**; layout/page yalnız `target.kind === 'ROOM'` dalında P4 bileşenlerine yönlenir (`TABLE` dalı P5'indir). Her yazma P0 deseniyle: `zod → assertCan → prisma.$transaction → audit → publish`; misafir yazması oturumsuzdur (token + hız sınırı + `FOR UPDATE` oda kilidi). Not/ürün adı çevirisi `TranslationProvider` soyutlamasıdır (varsayılan `none` = no-op, API anahtarı gerekmez). Push, `notify()`'ye dokunmadan gerçek zaman dinleyicisine takılan bir dağıtıcıdır (`notification.created` → `pushed_at` talebi → `web-push`); abonelik yoksa/başarısızsa bildirim satırı + SSE + onay penceresi zaten çalışır (geri düşüş).

**Tech Stack:** P0/P1/P5 ile aynı (Next.js 16.4, React 19, TS 5.9, Prisma 7.10, zod 4, zustand 5, Vitest 5, Playwright 1.64, pg-boss 12, `next-intl@4`). Yeni paket yok: `web-push@3.6` zaten bağımlılıktır. Ortam: `VAPID_PUBLIC_KEY?`, `VAPID_PRIVATE_KEY?`, `VAPID_SUBJECT?`, `TRANSLATE_PROVIDER?` (`none` | `gtx`, varsayılan `none`).

**Spec:** `docs/superpowers/specs/2026-10-31-merit-platform-design.md` — §3 (`MybarRequest*`, `PushSubscription`, `Notification`), §6.6 (MyBar), §9.1 (olaylar), §9.2 (bildirim/Web Push), §10 (iş günü), §11 (`mybar.*`), §13.2 (testler), §14 P4 satırı, §15 kabul 5 ve 10. Karar kaynağı: `docs/analiz/2026-10-31-anlayis-notu.md` §3 (K1 MyBar). Canlı referans: `D:\PROJELLER\minibarlatest` — `routes/misafir_qr_routes.py`, `routes/dolum_talebi_routes.py`, `utils/bildirim_service.py`, `utils/translate_service.py`, `static/js/bildirim_manager.js` (onay penceresi kuyruğu), `static/sw.js` (push). `templates/mybar_sunum.html` bir iç sunum/rapor sayfasıdır (misafir arayüzü değil); **taşınmaz**.
