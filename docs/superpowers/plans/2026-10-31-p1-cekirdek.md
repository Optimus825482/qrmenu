# P1 — Çekirdek Tanımlar ve Oturum Takibi Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merit OS yönetici kabuğuna tüm çekirdek tanımlama pencerelerini (otel, kat, oda tipi, oda, outlet, masa, kullanıcı, outlet ekibi, rol ve yetki matrisi), kurulum rehberini, online kullanıcı takibini, bildirim merkezini, denetim günlüğünü ve sistem ayarları penceresini eklemek; P0'dan devreden düzeltmeleri kapatmak.

**Architecture:** P0 iskeleti üzerinde (main `367b17c`): her yazma işlemi `zod → assertCan → prisma.$transaction → audit → publish` deseniyle `src/modules/core/server/admin/*` servislerinde; pencereler `src/shell/apps/definitions/*` altında, XP kabuğuna `src/modules/core/apps.ts` kayıtlarıyla takılır; listeler `definition.changed` ve `session.changed` SSE olaylarıyla canlı yenilenir. Tanım pencereleri otel bağlamlıdır (`needsHotel: true`); Oteller, Roller ve Denetim Günlüğü sistem genelidir.

**Tech Stack:** P0 ile aynı (Next.js 16.4, React 19, TS 5.9, Prisma 7.10, zod 4, zustand 5, Vitest 5, Playwright 1.64). Ek paket: `exceljs` (zaten kurulu) toplu oda/denetim dışa aktarımı için.

**Spec:** `docs/superpowers/specs/2026-10-31-merit-platform-design.md` (§3 veri modeli, §4 yetki/oturum, §5 kabuk, §9 gerçek zaman, §11 ayarlar, §14 P1 satırı, §15 kabul 1–3, 10)

- Dal: `p1/cekirdek`, `main`'den (`367b17c`). Uygulama `merit/`. LF satır sonu; commit kimliği `Erkan Erdem <ikinciyenikitap54@gmail.com>` (`git -c …`), Conventional Commits (Türkçe), trailer `Co-Authored-By: …`.
