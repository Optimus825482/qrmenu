# P0 — İskelet (Merit Platformu) Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merit platformunun çalışan iskeletini kurmak: Next.js 16 + Prisma 7 + PostgreSQL 17 projesi, tam veritabanı şeması ve seed, kimlik/oturum/yetki altyapısı, SSE gerçek zaman, pg-boss işleri ve ilk penceresiyle (Komuta Merkezi) çalışan Windows XP kabuğu.

**Architecture:** Tek Next.js uygulaması (`merit/`), App Router + Server Actions; iş kuralları `src/modules/*/server`, ortak altyapı `src/lib`, XP kabuğu `src/shell`. Gerçek zaman Postgres `LISTEN/NOTIFY` → süreç içi yayın → `/api/sse`; zamanlanmış işler pg-boss. Her yazma: Zod → `can()` → transaction → audit → publish.

**Tech Stack:** Next.js 16.4, React 19.3, TypeScript 5.9, Tailwind 4.3, Prisma 7.10 (+ `@prisma/adapter-pg`), pg 8, pg-boss 12, iron-session 9, bcryptjs 3, zod 4, zustand 5, Vitest 5, Playwright 1.64, date-fns-tz.

**Spec:** `docs/superpowers/specs/2026-10-31-merit-platform-design.md` (bu plan §2, §3, §4, §5, §9, §10, §11, §14-P0'ı uygular)

## Review Focus

1. **Yaz saati geçişi (Europe/Nicosia, Ekim sonu / Mart sonu):** 02:30 civarı kayıtların iş günü yanlış güne düşmemeli → Task 2 `businessDate` DST testi.
2. **Legacy Werkzeug hash bozuk/eksik format:** `pbkdf2:sha256:...` dışındaki bir hash ile giriş çökmemeli, "hatalı şifre" dönmeli → Task 5 `verifyPassword` testi.
3. **Aynı kullanıcı iki sekmeden aynı anda giriş:** iki `createSession` yarışında yalnız biri ONLINE kalmalı → Task 5 eşzamanlılık testi.
4. **SSE istemcisi bağlantıyı koparınca dinleyici sızıntısı:** abonelik kaldırılmalı, `listenerCount` düşmeli → Task 8 abort testi.
5. **Pasif kullanıcı / pasif otel / kapalı modül ile giriş ve yetki:** giriş reddi, `can()` false → Task 5 ve Task 6 testleri.
